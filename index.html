Find My Name

Votre prénom ou votre nom apparaît-il au générique d'un film ou d'une série ?

Clé API TMDB

Le site utilise la base de données gratuite The Movie Database (TMDB). Créez un compte, puis copiez votre clé API (v3) ou votre jeton d'accès en lecture (v4) depuis themoviedb.org/settings/api.

Elle est enregistrée uniquement dans ce navigateur.

    Comment ça marche ?

    1. Tapez un prénom ou un nom de famille.
    2. Le site cherche toutes les personnes portant ce nom dans la base TMDB (acteurs, réalisateurs, techniciens…).
    3. Il récupère leur filmographie complète et affiche tous les films et séries où ce nom apparaît au générique.
    4. Triez par popularité, date, note, et filtrez par type ou par rôle.
    Ce site utilise l'API TMDB mais n'est ni approuvé ni certifié par TMDB.
